- Project: https://github.com/IamAizen17/vexel-editor

The native SwiftUI implementation adapts the reference application's navigation and screen organization, including onboarding, project home, presets, settings, editor chrome, timeline, layer management, properties, graph and curve editors, effect browser, media, audio, camera, captions, elements, plugins, and export UI.

The Android Compose source has been translated into SwiftUI and is not copied as Kotlin source files. The UI behavior and organization are derivative adaptations of the GPL-covered reference. This repository is distributed under GPL-3.0; see LICENSE.

The current UI milestone uses presentation/demo state for editor interactions. It does not claim that the Android editing engine, renderer, project storage, or export implementation has been ported.


The app also bundles `App/Resources/effects.json`, generated by the reference repository's `RegistryArtifactsTest` from `core/model/EffectRegistry.kt` at the audited revision. It is the source-defined 73-effect metadata catalogue (IDs, categories, targets and parameter schemas), not an independent implementation of the effect algorithms. Its GPL-3.0 provenance is covered by this repository's license and the source attribution above.
